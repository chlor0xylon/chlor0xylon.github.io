## Feature visualization

One of Distill's foundational articles is called _Feature Visualization_ [@olah2017featureVisualization]. It describes how neural networks designed for computer vision tasks can be probed to reverse-engineer the learned patterns cristallized into their weights after the training phase[^note-older-feature-viz].

[^note-older-feature-viz]: Even in 2017, visualizing features by creating images to maximize activations wasn't exactly new. The numerous papers cited in Distill's _Feature Visualization_ is evidence of those previous attempts, some as early as 2009, even before [AlexNet](https://en.wikipedia.org/wiki/AlexNet)'s breakthrough.

It's safe to say the work carried out by Distill's authors has inspired many computer vision interpretability endeavors in mechanistic interpretability following the developments in convolutional neural networks. Other interesting work worth looking at on Distill include exploring ever more specialized vision mechanisms such as curve detectors [@cammarata2020curveDetectors] or spacial frequency edge detectors [@schubert2021highLowFrequencyDetectors] and differentiable image parametrizations [@mordvintsev2018differentiableParameterizations].



## Reverse-engineering visual patterns

To _visualize_ features in this context means to synthesize images by whichever means possible, comprising patterns that maximize some given activations or outputs of a neural network, in order to gain insights about what the model perceives and how it ``interprets'' the inputs. In other words it's about finding _prototypical_ images that make particular neuron groups fire in a certain way[^note-on-fire-modes]. The proper mathematical term is _preimage_, but it has nothing to do with actual images made of pixels in the general sense, so to avoid that ambiguity I will henceforth refer to such artificial images simply as _prototypes_ in the remaining of this post, to stick to the literature's coined terminology.

[^note-on-fire-modes]: Said chosen groups can mean a specific neuron, or a collection of designated neurons. Distill's article _The Building Blocks of Interpretability_ [@olah2018buildingBlocks] showcases some neuron grouping choices for activation maximization.

One of the simplest ideas to compute _prototype images_ is to treat the model as a (differentiable) black box processing its input space, and the exposed outputs.

:::note
The output space of a neural network is closely linked to its training setup. Mid-2010's-era frontier image models such as Microsoft's ResNet were trained from the start to perform supervised image classification, so the main outputs are the logits, even though they also expose _pooled outputs_, i.e. the penultimate pre-logits layer's outputs, learning arguably more general features. Current state-of-the-art ViT models are often pre-trained in an unsupervized fashion, to learn useful representations that can be leveraged for more specialized downstream tasks. Those models usually expose image patch tokens, as well as a CLS token in their pooled outputs, and sometimes register tokens [@darcet2024visionTransformersNeedRegisters] if included in their architecture.
:::


To put it plainly, let $f$ be a provided, trained, frozen neural network accepting images in (a subset of) $\mathcal{X} = \mathbb{R}^{C \times W \times H}$ in input, that returns output vectors $\mathcal{Y} \ni \mathbf{y} = f(\mathbf{x})$. To find a prototype $\tilde{\mathbf{x}}$ in input space for some objective function $s: \mathcal{Y} \rightarrow \mathbb{R}$ means to solve

$$
\tilde{\mathbf{x}} = \arg\max_{\mathbf{x} \in \mathcal{X}} s(f(\mathbf{x}))
$$

which translates into ``finding an input that represents its class or target latent representation perfectly according to measure $s$''.

For example, $s$ can denote:

- the logit at index $k$: $s(\mathbf{y}) = \mathbf{y} \cdot \mathbf{e}_k$ (pre-softmax) in a classification model
- the cosine of the angle between the output CLS token and a target vector $\mathbf{y}_0$ whose semantic meaning we're interested in: $s(\mathbf{y}) = \frac{\mathbf{y} \cdot \mathbf{y}_0}{\|\mathbf{y}\|\|\mathbf{y}_0\|}$, in a general feature extractor vision model
- the activation of a specific internal neuron

In this setup, the optimized variable is the input to the frozen network, a.k.a. the data, as opposed to the training phase where the data was fixed, and drawn from a dataset, and the network's weights were the optimized variables. The point is then to use optimization techniques to synthesize input images that maximally activate specific neurons or layers.

For any neural network of more than, say, at least a few layers and a handful of input variables, such a mathematical problem is not remotely tractable due to the deep and non-linear nature of neural networks. Thus, only approximated solutions are in order. To compute one, we can resort to iterative gradient ascent, backpropagating up the network to the inputs, leveraging the the network's mapping function $f$ being differentiable. One single step of the gradient ascent process goes like this:

$$
\mathbf{x}^{(t+1)} \gets \mathbf{x}^{(t)} + \alpha \nabla_{\mathbf{x}} (s \circ f)(\mathbf{x}^{(t)})
$$

## The trials and tribulations of computing prototypes

### The problem with raw gradients

Naively deriving a solution to the above mathematical problem using the above update rule implicitely assumes that the model's gradients driving the walk in its input space are sufficiently well-behaved to stabilize around images intelligible by humans. However, neural networks usually fall short of supporting that hypothesis.

Conventional discriminative vision-based neural networks are _not_ designed to derive images back from the latent space or preserve an invertible encoding of the original inputs[^note-highly-specific-reversible-nn].

[^note-similarity-transformers-hash]: The crucial difference is that Transformers seek to preserve and reorganize information so that it is stable to local noise in the continuous variables, whereas cryptographic hashes irreversibly destroy evidence of similarity and reshuffle discrete inputs.

Rather, they are optimized to aggregate visual cues and compress information from the inputs into progressively more abstract latent representations of densely packed arrays of numbers that are supposed to be more or less invariant to semantic-preserving changes in the input space. These latents are useful for downstream prediction tasks. Forefront convolutional kernels in CNNs and Transformers patch embedding kernels usually look like Gabor filters or random noise patches [@alexnet2012; @dosovitskiy2021vit].

To me, legacy convolutional models aggregation strategy resembles an elaborate interferometry system detecting edges and alignments of visual patterns [@zeiler2014visualizingCNNs], whereas the Transformer-based models aggregation strategy consisting in gradually refining the residual stream latents is more reminiscent of internal state buffers in cryptographic hash algorithms such as AES[^note-similarity-transformers-hash].

[^note-highly-specific-reversible-nn]: Except highly-specific architectures designed from the ground-up to also be able to possibly process the data in reverse, like Variational Auto-Encoders.

I guess that's expected as well, because unlike convolution kernels, patch embedding kernels have to capture details at the edge of patch borders, whereas convolution filters tend to focus most of their energy in the center, and convoluting does the rest.

Anyway, as a matter of fact, vision models tend to backpropagate very noisy gradients in the input space, making them almost useless for reconstructing natural images. The presence itself of high-frequency noise in individual filters is not a proof that vision models invariably favor noisy images--because even high frequency patterns can arguably cancel out into lower frequency results--but at least it strongly hints at it[^note-not-llm]. Since CNN and ViT alike seem to rely mostly on locally jittered patterns to capture the semantics of images, nothing really prevents activation maximization from falling into equally jittered local optima, completely overriding the prototype buffer with unnatural high frequency noise. In the field of computer vision, these images are referred to as _adversarial images_.

This poses a serious problem to gradient ascent approaches, because iteratively updating the pixels of a randomly initialized source image leads to high-frequency visual gibberish that completely ignores the reality of images taken from real-world physical scenes a.k.a. _natural images_.

### Regularizing in model input space

Fortunately, all is not lost. Numerous Pre-2020 research results tackle prototype generation for convolutional networks. I will not reiterate here the already plentiful literature reviews of the various strategies they came up with to circumvent adversarial images. Both @Nguyen2019UnderstandingVisualizing and @olah2017featureVisualization provide one. But let's only state that they all involve some form of regularization in the model input space. Most of them aim to curb parasitic high frequencies, with various implementations techniques (for example directly in the gradients, or in the buffers; or indirectly via intermediary image transforms interleaved with gradient steps).

## The current state of feature visualization

### The shift in paradigm in image computer vision

How did we get from discriminative image neural networks in 2015 categories to task-agnostic models yielding universal image embeddings in 2025?

In the course of a global acceleration in machine learning research, the advent of Transformers [@vaswani2017attention] has completely overhauled the field of computer vision the same way NLP was revolutionized by Transformers a few years prior, coming from cumbersome recurrent neural networks. 

Since the publication of the the first articles about feature visualization on Distill, ViTs have largely taken over convolutional models for vision tasks. Convolutional neural networks have now somewhat fallen into disfavor, and for a good reason: Transformers are more versatile, perform better and and allow to combine tokens of virtually any modality, text and images alike. This major architectural modernization--from ResNet [@2016resnet], to ConvNext [@2023convnext] to ViT [@dosovitskiy2021vit]--unlocked drastically better generalization power between models from the mid-2010's and models from the mid-2020's.

Over the course of the last five years or so, the quality of image latent representations in frontier vision models has improved a lot due to scaling up both the neural networks and the datasets in use, and improved training methods. Transitioning from discriminative supervised learning to soft self-supervised _knowledge distillation_ learning certainly has a lot to do with improvements in state-of-the-art models indeed.

:::note
A very nice review of the iterative research about transcending supervision and leveraging better data augmentation techniques in computer vision can be found on [Lil'log](https://lilianweng.github.io/) [@weng2021contrastive; @weng2019selfsup]. I find that it's a very informative overview of the main contrastive learning techniques that heralded novel, more implicit, task-agnostic, better regularized, abstracted-away learning paradigms such as DINO's teacher-student system for robust image representations [@emerging2021dinov1].
:::

My personal impression is that computer vision as a domain now elicits far less curiosity about the models' inner working principles and interpretability than it used to do when convolutions were the norm, and it has gotten dragged by fast-paced developments driven by a skyrocketing interest in the field of natural language processing.

I think an indicative example of that trend is the renowned [Transformer Circuits Thread](https://transformer-circuits.pub/), which has shifted from computer vision to NLP since its inception. It seems that vision models have now become a commodity taken for granted, that gets incorporated in all major new image-text model released out there, while the new _El Dorado_ of language processing took control of the AI race monopolizing all the attention (pun intended). Prototypes are the remnants of a forgotten experiment. Mechanistic interpretability now focuses on other means of breaking down neural networks.

### A hypothesis on the quality of latent representation
I hypothesize that with more robust representations, proper regularization, increased generalization and denser datasets compacted into the latent space, come better model calibration and smoother gradients to backpropagate, possibly. This is a hunch I get from reading @sensitivity2018 performing a sensitivity analysis on the MNIST dataset. They show that gradients of the last layers of the network are smoother and less noisy near training points. MNIST is particular in that it's a tiny, minuscule dataset with a handful of extremely repetitive patterns. But cramming representations for billions of diverse images into a few hundred dimensions with proper data curation ensuring balance and representativeness like it's the case for current SOTA models like DINO should yield latent spaces covering the manifold of natural images more densely and smoothly. I have no proof of it, though. This is probably a massive oversimplification.

Another sensible way of phrasing that hunch would be the following: formerly, classification-trained discriminative models had the possibility to take hacky shortcuts in order to cut through the visual patterns and return the correct label. For example, early convolutional neural networks are typically known to rely on texture information [@imagenet2018texturebias], or at least local shapes [@burgert2026imagenettrained], which isn't a bad proxy anyway, but limits the so-called ``global understanding'' of a scene, which Transformers excel at by comparing each patch with one another.

The relative robustness of late frontier convolutional networks only came from scaling the sheer amount of different classes[^note-number-classes-imagenet] to force them to refine their understanding. By contrast, nowadays, models of DINO's caliber, which are trained on datasets three orders of magnitude larger[^note-number-images-dino-training] and forced to capture subtle internal pieces of visual context in an unsupervized learning setup, should be able to encode semantic relationships between images more finely, albeit in a latent space with roughly the same number of dimensions[^note-dimensions-models]. If true, that intuition suggests it should be less tricky to produce prototypes from those modern models because they compress visual information less aggressively.

[^note-number-classes-imagenet]: The ImageNet-1K dataset [@imagenet1k2012], used to train ResNets, is comprised of merely 1.4 million images split up into 1000 categories.

[^note-number-images-dino-training]: The LVD-1689M dataset, used to train DINOv3 models, is comprised of 1.7 billion images scrawled from the web. 

[^note-dimensions-models]: ResNets models have 512 dimensions (pre-logits). DINOv3 latent spaces range from 384 to 4096 depending on the variant and size, but the comparison holds between equivalently-sized `microsoft/resnet-18` and `facebook/dinov3-convnext-tiny-pretrain-lvd1689m` or `facebook/dinov3-convnext-small-pretrain-lvd1689m` (HuggingFace model identifiers). Unlike classifiers models, with no need for grouping latents into 1000 regions of space.

### The incentive to compute prototypes on the newest frontier models
Despite the aforementioned developments in self-supervised learning, not many groundbreaking achievements have happened since the late-2010's when it comes to generating image prototypes of vision models. As stated above, that area of research seems to have fallen out of use. 

There _is_ a series of recent experiments and papers that are worth seeing, however. A 2023 paper @fel2023unlocking by ML interpretability researcher Thomas Fel revisited prototype optimization on DINOv2. The resulting showcased prototypes are visually quite compelling, by means of constraining the image spectrum's magnitude prior. The method's name was coined MACO, which stands for _magnitude-constrained_ optimization. Overall, his [personal website](https://thomasfel.fr/) is really well done, and his papers are fascinating to read, striking the right balance between technicality and didacticism.

That, and the will to test whether my above hypothesis is true, is what made me want to try to reproduce it on DINOv3.

## Computing latent concepts with dictionary learning

Before visualizing concepts as images, we need to compute them in the DINOv3's latent space, to gain better understanding of the representations. In order to achieve that, we'll learn a dictionary of the most prominent concepts directions arising in the abstract latent space. That's called _dictionary learning_. 

Dictionary learning is a data representation learning technique that discovers a set of interpretable building blocks, enabling complex data to be expressed as sparse combinations of simple patterns, or atoms, that together make up a _dictionary_. It provides compact, meaningful representations for tasks such as denoising, compression, and feature extraction. Unlike PCA or SVD, dictionary learning approaches usually attempt to make the decomposition _sparse_, whose byproduct is usually better interpretability. It is very akin to how data compression works by seeking a better representation basis to encode the data in the most compact way possible. Think about how the JPEG standard decomposes each $8 \times 8$ block of pixels onto the 64-element basis of cosine waveforms. These waveforms put together do not carry inherently more information as the simple canonical basis of the 64 individual dots in the grid, because both groups form a _basis_, but it turns out that real-world signals are usually better explained by smooth variations resembling sparse combinations of cosine waves, and this better prior it allows a lower-rank representation to describe a typical signal. Sparsity is a desirable property when doing coding, either for storage space purposes, or for the sake of interpretability. Because of that, dictionary learning is also known as sparse coding.

### Dictionary learning
I will rely on @holistic2023fel, a paper which unifies the concept extraction variants attempts in the literature and compares them. One of the methods presented was coined CRAFT, standing for _Concept Recursive Activation FacTorization for Explainability_, from the preceding paper @craft2023fel, which adds the constraint of positivity for the learned priors, in order to only consider positive activations as meaningful. They also propose an attribution method for visualizing the concept activations in images. Here I'm only interested in the first part, about learning the dictionary.

The setup goes like this: let $\mathbf{X} \in \mathbb{R}^{n\times p}$ be a set of $n$ captured activations in dimension $p$ from the latents from a vision model taken from a provided collection of images. Let $r$ be a positive integer, denoted as the rank of the decomposition. The positive dictionary learning approach consists in solving the following neighbouring problem:

$$
\arg\min_{\mathbf{U}\in \mathbb{R}^{n\times r}, \, \mathbf{W}\in \mathbb{R}^{p\times r}} \|\mathbf{X} - \mathbf{UW}^\top \|_F^2 \quad \text{s.t.} \quad \mathbf{W}, \mathbf{U} \ge 0
$$

where $\mathbf{W}$ is the _dictionary of concepts_ onto which the dataset is projected and $\mathbf{U}$ is the dataset decomposition, i.e. the assignments of each data point to each of the $r$ concepts. For dictionary learning to mean anything, $r$ and $n$ must be chosen so that $r < n$.

Note that $\mathbf{U}$ and $\mathbf{W}$ are required to belong to the positive orthant of matrices with **non-negative values**. That constraint is a deliberate modeling choice. Note that the solution space is convex, but the search is made arduous because positivity prevents the use of off-the-shelf linear algebra results. This formulated problem  is known as the **Non-Negative Least Squares problem** (NNLS), and I first encountered during my Master's Thesis in the context of beamforming in transmission-related problems.


### Solving procedure
Solving the above mathematical problem can be approached in at least a few different manners. In Fel's PhD thesis manuscript [@fel2025sparksexplainabilityrecentadvancements], in section C.1.3 wlong with the implementation details of CRAFT, they explain that they used a method called alternating direction method of multipliers (ADMM for short), which I also encountered during my Master's Thesis, because it arises a lot in the literature about applied mathematical optimization problems with cumbersome constraints such as non-negativity. The drawback of this algorithm in our present use is that it requires storing the values in memory during the iterative solving process, and even duplicating variables to account for the separation of optimization and constraint enforcement, as per the ADMM framework. And it does not scale particularly well, given the dataset can be huge. For example, the full ImageNet dataset comprised of 1.3 million images, coded over 384 dimensions of 32-bit floating point numbers would take up about 2GB in memory. Fully manageable even on most modern laptops even in the VRAM, but we're nearly on the edge. Any $\times 5$ scaling of dataset and memory IO would probably becomes a noticeable limiting factor.

Yet, in hindsight, we are only really interested in the final dictionary $\mathbf{W}$ solution, _not_ the full decompositions $\mathbf{U}$ of our dataset, which can be recomputed at will once $\mathbf{W}$ is set. The problem is indeed separable, thanks to the following identify:

$$
\|\mathbf{X} - \mathbf{UW}^\top \|_F^2 = \sum_{i=1}^{n} \| \mathbf{X}_{[i,:]} - \mathbf{U}_{[i,:]} \mathbf{W}\|_2^2
$$
which goes to show that $\mathbf{W}$ could be conceptually updated by only considering a subset of the dataset elements at a time indexed in $\llbracket 1, n \rrbracket$, akin to how neural networks update their weights by considering an objective computed on small parts of the dataset at a time.

I don't like having the mental pressure of accounting for my 32GB of RAM limitation (let alone VRAM culminating at a quarter of that), or having to rent a VPS if I ever want to scale up my experiment past ImageNet in the future, so a streaming algorithm would be in order to avoid storing the decompositions. Possibly at the expense of convergence speed, exactness or correctness. So I began looking for such an algorithm. That in itself, was a small experiment to try.

And so I found a promising paper about exactly that [@onlinelearning2009] exposing a procedure for online dictionary learning. By the way, Julien Mairal is also a credited author of the three DINO papers. They address the following problem:

$$
\arg\min_{\mathbf{D} \in \mathbb{R}^{m\times k}, \alpha \in \mathbb{R}^{k\times n}} \|\mathbf{X} - \mathbf{D} \alpha \|_F^2 + \lambda \|\alpha\|_{1,1} \quad \text{s.t.} \quad \mathbf{D} \in \mathcal{C}
$$
where $\mathcal{C}$ is the convex set of matrices whose column vectors belong to the unit ball for the $L_2$ Euclidian norm: $\mathcal{C} = \{\mathbf{D}\in \mathbb{R}^{m\times k}, \forall j \in \llbracket 1, k \rrbracket, \mathbf{d}_j^\top \mathbf{d}_j \le 1\}$.

:::note
For the sake of clarity, I adopted their notations, but here are equivalences between their conventions and the ones above:

- $k \longleftrightarrow r$ is the rank (or dictionary size)
- $m \longleftrightarrow p$ is the data dimensionality
- $n \longleftrightarrow n$ is the dataset size
- $\mathbf{D} \in \mathbb{R}^{m \times k} \longleftrightarrow \mathbf{W} \in \mathbb{R}^{p \times r}$ is the dictionary (or learned weights of interest)
- $\alpha \in \mathbb{R}^{k \times n} \longleftrightarrow \mathbf{U}^\top \in \mathbb{R}^{r \times n} $ are the assignments (or codes)
- $\mathbf{X} \in \mathbb{R}^{m \times n} \longleftrightarrow \mathbf{X} \in \mathbb{R}^{n \times p}$
:::

The main two differences are that the search space and the regularization term. They use the unit ball for the $\|\cdot\|_{2,\infty}$ column-wise norm in lieu of the orthant of poitwise non-negative elements, and they regularize the assignments $\alpha$ with the $L_1$ norm to favor sparse solutions. Regularizing the weights also avoids degeneracy in the solutions due to the degree of freedom of rescaling recoprocally $\alpha$ and $\mathbf{W}$.

They come up with an algorithm with proven convergence for solving that problem. The algorithm in question has been reproduced below:


```algorithm
Algorithm: Online Dictionary Learning [@JMLRv11mairal10a]
Require $\mathbf{x} \in \mathbb{R}^m \sim p(\mathbf{x})$, $\lambda \in \mathbb{R}$, $\mathbf{D}_0 \in \mathbb{R}^{m \times k}$, $T$
$\mathbf{A}_0 \in \mathbb{R}^{k \times k} \gets \mathbf{0}$, $\mathbf{B}_0 \in \mathbb{R}^{m \times k} \gets \mathbf{0}$
For $t = 1$ to $T$
  Draw $\mathbf{x}_t$ from $p(\mathbf{x})$
  State Sparse coding: compute $\alpha_t$ such that
    $$
    \alpha_t \triangleq \arg\min_{\alpha \in \mathbb{R}^k} \frac{1}{2}\|\mathbf{x}_t - \mathbf{D}_{t-1}\alpha\|_2^2 + \lambda \|\alpha\|_1
    $$
  $\mathbf{A}_t \gets \mathbf{A}_{t-1} + \alpha_t \alpha_t^T$
  $\mathbf{B}_t \gets \mathbf{B}_{t-1} + \mathbf{x}_t \alpha_t^T$
  State Update dictionary $\mathbf{D}_t$ with $\mathbf{D}_{t-1}$ as a warm restart
    $$
    \mathbf{D}_t \triangleq \arg\min_{\mathbf{D} \in \mathcal{C}} \frac{1}{t}\sum_{i=1}^t \left(\frac{1}{2}\|\mathbf{x}_i - \mathbf{D}\alpha_i\|_2^2 + \lambda \|\alpha_i\|_1\right) \\
	= \arg\min_{\mathbf{D} \in \mathcal{C}} \frac{1}{t} \left( \frac{1}{2} \mathrm{Tr}(\mathbf{D}^\top \mathbf{DA}_t - \mathrm{Tr}(\mathbf{DB}_t) \right)
    $$
  Return $\mathbf{D}_T$
EndFor
```

```algorithm
Algorithm: Dictionary Update [@JMLRv11mairal10a]
Require $\mathbf{D} = [\mathbf{d}_1,\dots,\mathbf{d}_k]\in \mathbb{R}^{m\times k}$ (input dictionary)
$\mathbf{A} = [\mathbf{a}_1,\dots,\mathbf{a}_k]\in \mathbb{R}^{k\times k}$
$\mathbf{B} = [\mathbf{b}_1,\dots,\mathbf{b}_k]\in \mathbb{R}^{m\times k}$
Repeat
  For $j = 1$ to $k$
    State Update the $j$-th column:
      $\mathbf{u}_j \leftarrow \big(\mathbf{b}_j - \mathbf{D}\mathbf{a}_j\big) / \mathbf{A}[j,j] + \mathbf{d}_j$
      $\mathbf{d}_j \leftarrow \mathbf{u}_j / \max\big(\left\|\mathbf{u}_j\right\|_2, 1\big)$
  EndFor
Until convergence
Return $\mathbf{D}$ (updated dictionary)
```

So, looking into the procedure reveals that the optimization performs a step in two stages given a batch:

- first, compute the codes, or assignments, of the elements in the batch
- then aggregate statistics about the codes into two buffers and update the dictionary state


In an extended journal version of the paper [@JMLRv11mairal10a], the authors also tackle regularization variants, notably the non-negative matrix factorization problem (NMF for short) taken from another referenced line of research[^note-nmf], as part of the broader framework of different constraint sets for the dictionary and the codes.

[^note-nmf]: That's where we can learn, among other things, that non-negative matrix factorization for sparse coding seems to date back as early as 2001.

They mention the alternative constraint set $\mathcal{C}^\prime = \{\mathbf{D}\in \mathbb{R}^{m\times k}, \forall j \in \llbracket 1, k \rrbracket, \mathbf{d}_j^\top \mathbf{d}_j \le 1 \text{ and } \mathbf{d}_j \ge 0\}$ for $\mathbf{D}$, as well as the eventuality of also constraining $\alpha \ge 0$ independently. More importantly, they mention the simplest problem featuring the same objective with only positivity constraints on $\mathbf{D}$ and $\alpha$, amounting to solve $\arg\min_{\mathbf{D}, \alpha} \|\mathbf{X} - \mathbf{D} \alpha \|_F^2 + \lambda \|\alpha\|_{1,1}$ such that $\mathbf{D}, \alpha \ge 0$. One comment about this particular variant is interesting: 
 
 > ``When $\lambda = 0$, this formulation is equivalent to NMF. The only difference with the dictionary learning
problem is that non-negativity constraints are imposed on $\mathbf{D}$ and the vectors $\alpha_i$. A simple modification of our algorithm (...) allows us to handle these constraints, while guaranteeing to find a stationary point of the optimization problem.''

Wonderful, I thought. This is exactly the setup we're looking for. The implications here affect both steps of the overall procedure, namely the initial sparse coding solve step (by constraining additionally $\alpha$ to remain non-negative), and the projections in the dictionary update routine.




### Implementation

In order to online compute the dictionary according to the approach proposed by @holistic2023fel retaining concepts of positive activations only, I wrote a Python script that given a huggingface model and a dataloader wrapping a PyTorch datasest, evaluates the latents of some random crops of the provided images and saves the resulting vectors in Numpy's binary file format. Then, I made another separate PyTorch dataset wrapper to index those saved vectors materialize them from their saved batch files into memory, shuffle them, interleave into batches on the fly, and stream them to whatever other tool I need, like a dictionary learning procedure.

The numerical computations of dictionary learning with lots of vectorized operations are natural fit for [Jax](https://docs.jax.dev/en/latest/). Unlike PyTorch, `jax` fuses operations by default because it compiles the computation graph and it allows looped computations to happen faster by avoiding python interruptions between operations. This is especially handy for iterative algorithms to solve linear algebra problems. Before this project I was familiar with PyTorch but I had never used Jax so it was a good use case to learn.

In the code, I kept the original notations with $\mathbf{W} \in \mathbb{R}^{p \times r}$ and $\mathbf{U} \in \mathbb{R}^{n \times r}$. However, since $\mathbf{U}$ is conceptually reserved for the full dataset codes, and is never materialized in memory, so I named its batched counterpart $\mathbf{H} \in \mathbb{R}^{b\times r}$ where $b$ is the batch size with obviously $b < n$. At any step, we draw $\mathbf{X} \in \mathbb{R}^{b\times n}$ and apply the above algorithm.

Thus the main training loop looks like this:

```python
def train_step(
    W: jnp.ndarray,   # (DATA_DIM, DICT_SIZE)
    A: jnp.ndarray,   # (DICT_SIZE, DICT_SIZE)
    B: jnp.ndarray,   # (DATA_DIM, DICT_SIZE)
    X: jnp.ndarray,   # (BATCH_SIZE, DATA_DIM)
    H0: jnp.ndarray,  # (BATCH_SIZE, DICT_SIZE)
    T: int,           # global step counter
    lam: float,
):
    W_prev = W
    H = nonnegative_lasso_fista(W=W, X=X, lam=lam, H0=H0)
    W, A, B = update_dictionary(W=W, H=H, X=X, A=A, B=B, T=T)
    return W, A, B
```

### Non-negative LASSO sparse coding step
The modified sparse positive coding step to compute $\alpha_t = \arg\min_{\alpha \in \mathbb{R}^k} \frac{1}{2}\|\mathbf{x}_t - \mathbf{D}_{t-1}\alpha\|_2^2 + \lambda \|\alpha\|_1$ is a procedure in and of itself. Thanks to the magic of LLMs nowadays, I got to know that there exists a respectable algorithm that lends itself well to the non-negative LASSO problem, called Fast Iterative Shrinkage-Thresholding Algorithm (a.k.a. FISTA in the literature) [@teboulle09fista]. To be honest, I wasn't particularly interested in the details of this minor technicality in the grand scheme of dictionary learning, so I gladly let Codex 5.4 do the research and work out the Jax function for it. The only relevant practicality to be aware of is that it involves an iterative procedure of its own, so fine-tuning the tolerance and/or an iteration cap is a thing to look out for. Below is the code for reference.

```python
def nonnegative_lasso_fista(
    W: jnp.ndarray, X: jnp.ndarray, lam: float, H0: jnp.ndarray
) -> jnp.ndarray:
    tol = 1e-4
    eps = 1e-8
    max_iter = 30
    # Solve for nonnegative codes H with W held fixed:
    #     min_{H >= 0} 0.5 * ||X - H W^T||_F^2 + lam * ||H||_1
    #
    # Row-major convention:
    # X has shape (num_samples, data_dim),
    # W has shape (data_dim, size_dict),
    # H has shape (num_samples, size_dict),
    # so X ~= H @ W.T.

    # The scalar `lam` controls the L1 penalty on optimized H.
    G = W.T @ W
    B = X @ W

    # Precompute the Gram matrix W^T W and the data term X W.
    # The gradient of 0.5 * ||X - H W^T||_F^2 is H (W^T W) - X W.
    L = jnp.linalg.norm(G, 2)
    step = 1.0 / L

    H = H0
    Y = H0
    t = 1.0

    def cond_fn(state):
        _, _, _, iter_idx, rel_change = state
        return jnp.logical_and(iter_idx < max_iter, rel_change > tol)

    def body_fn(state):
        H, Y, t, iter_idx, _ = state

        grad = Y @ G - B
        # Because we also impose H >= 0, the proximal map of the L1 term
        # becomes a positive soft-thresholding step:
        # prox(z) = max(0, z - step * lam).
        H_next = jnp.maximum(0.0, Y - step * (grad + lam))

        # Standard FISTA momentum update.
        t_next = 0.5 * (1.0 + jnp.sqrt(1.0 + 4.0 * t * t))
        Y_next = H_next + ((t - 1.0) / t_next) * (H_next - H)

        diff_norm = jnp.linalg.norm(H_next - H, ord="fro")
        base_norm = jnp.maximum(jnp.linalg.norm(H, ord="fro"), eps)
        rel_change = diff_norm / base_norm

        return H_next, Y_next, t_next, iter_idx + 1, rel_change

    H, _, _, _, _ = jax.lax.while_loop(cond_fn, body_fn, (H, Y, t, 0, jnp.inf))
    return H
```

### Dictionary update step

The dictionary update step is pretty much about following to the letter instructions from the algorithm, with the additional projection to enforce non-negative values for the new dictionary columns. Also, instead of simply accumulating the statistics, I average them with the simple online mean update formula to avoid overflow. Since the values of columns of $\mathbf{A}$ and $\mathbf{B}$ are used in tandem, using the averaged aggregate values scaled by $\frac{1}{T}$ ($T$ is the global time step) instead of the raw sums does not change anything to the algorithm  in the running inner loop of the dictionary update step $\mathbf{u}_j \leftarrow \big(\mathbf{b}_j - \mathbf{D}\mathbf{a}_j\big) / \mathbf{A}[j,j] + \mathbf{d}_j$. I got rid of the original columnn-wise $L_2$ unit ball constraint for the dictionary atoms and, obviously, I added the projection onto the set of positively-valued vectors. Below is the Jax code for reference.

```python
def update_dictionary(
    W: jnp.ndarray,
    H: jnp.ndarray,
    X: jnp.ndarray,
    A: jnp.ndarray,
    B: jnp.ndarray,
    T: int,
) -> Tuple[jnp.ndarray, jnp.ndarray, jnp.ndarray]:
    max_passes = 30
    tol = 1e-4
    eps = 1e-8

    # Accumulate the surrogate statistics A and B
    A = (1 - 1 / T) * A + 1 / T * H.T @ H
    B = (1 - 1 / T) * B + 1 / T * X.T @ H

    def update_column(j: int, W_current: jnp.ndarray) -> jnp.ndarray:
        # Extract a_j, b_j, and d_j
        a_j = A[:, j]
        b_j = B[:, j]
        d_j = W_current[:, j]
        a_jj = A[j, j]

        # u_j <- (b_j - W a_j) / A[j, j] + d_j
        safe_denom = jnp.where(a_jj > 0.0, a_jj, 1.0)
        u_j = (b_j - W_current @ a_j) / safe_denom + d_j
        u_j = jnp.where(a_jj > 0.0, u_j, d_j)

        # d_j <- max(u_j, 0)
        d_j_next = jnp.where(u_j > 0.0, u_j, 0.0)
        return W_current.at[:, j].set(d_j_next)

    def cond_fn(state):
        _, pass_idx, rel_change = state
        return jnp.logical_and(pass_idx < max_passes, rel_change > tol)

    def body_fn(state):
        W_current, pass_idx, _ = state
        # Update the j-th column for j = 0, ..., k - 1
        W_next = jax.lax.fori_loop(0, W_current.shape[1], update_column, W_current)
        diff_norm = jnp.linalg.norm(W_next - W_current, ord="fro")
        base_norm = jnp.maximum(jnp.linalg.norm(W_current, ord="fro"), eps)
        rel_change = diff_norm / base_norm
        return W_next, pass_idx + 1, rel_change

    W, _, _ = jax.lax.while_loop(cond_fn, body_fn, (W, 0, jnp.inf))
    return W, A, B
```
